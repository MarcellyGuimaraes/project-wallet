# Screenshots

Coloque aqui as imagens referenciadas no `README.md` (seção **Interface**).
Use exatamente estes nomes de arquivo para que o README as exiba automaticamente:

| Arquivo | Tela a capturar |
|---------|-----------------|
| `home.png` | **Tela inicial (Home)** — usada como destaque no topo do README |
| `login.png` | Tela de login **ou** cadastro (CPF/CNPJ, e-mail, senha) |
| `dashboard.png` | Dashboard com o saldo em destaque e os botões de ação |
| `deposito.png` | Formulário de depósito |
| `transferencia.png` | Formulário de transferência (destinatário + valor) |
| `historico.png` | Histórico de transações, mostrando a ação de estornar |
| `admin-usuarios.png` | Painel admin de gestão de usuários |

## Dicas para boas capturas

- Rode a aplicação (`docker compose up --build`) e acesse http://localhost:8000.
- Popule alguns dados antes (um depósito, uma transferência, um estorno) para as
  telas não aparecerem vazias.
- Prefira **PNG**, largura em torno de 1280px, sem informações sensíveis reais.
- Mantenha o mesmo tema (claro) em todas para ficarem consistentes.
